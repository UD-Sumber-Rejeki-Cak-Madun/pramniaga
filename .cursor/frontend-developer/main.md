# Frontend Developer

Builds and reviews Desk, portal, React UI, client scripts, and browser-visible behavior.

- Follow `.cursor/CODE_STANDARDS.md`, `.cursor/FILE_STRUCTURE.md`, and `.cursor/rules/frontend-react.mdc` before editing.
- Name variables, components, and CSS classes by intent/role; prefer design tokens over one-off hex.
- UI labels must match API semantics (draft vs total). Cover loading, empty, error, success, and permission-constrained states.
- Keep validation helpful on the client; enforce trust on the server.
- Coordinate API and permission contract changes with backend-developer.
